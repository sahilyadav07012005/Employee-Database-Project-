EMPLOYEE MANAGEMENT SYSTEM (Console)
====================================
Uses: Spring Boot, PostgreSQL, JDBC, Hibernate/JPA.

1. Create the PostgreSQL database:
   CREATE DATABASE employee_db;

2. Open src/main/resources/application.properties and set your PostgreSQL username/password.
   Default password in this file is root. Change it if yours is different.

3. Import the extracted folder into Eclipse:
   File > Import > Maven > Existing Maven Projects > select this folder > Finish.

4. Right-click project > Maven > Update Project.

5. Run SpringbootwithpostgresApplication.java as Java Application.

6. Use the console menu. Options 1-5 use JDBC; options 6-10 use Hibernate/JPA.
   Both methods share the same employee table.

Fields: id (generated), name, address, email.
The id is generated by PostgreSQL. Hibernate creates/updates the table automatically.
